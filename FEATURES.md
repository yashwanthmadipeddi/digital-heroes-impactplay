# ImpactPlay enhancement set

ImpactPlay is the cricket-themed alternative concept for the Digital Heroes assignment architecture.

1. Cricket-first member experience with runs, wickets, format, and result inputs.
2. Transparent 1–45 Impact Form Score derived from match performance.
3. Latest-five match retention with duplicate-date protection.
4. Scroll-triggered section reveals with blur-to-sharp transitions.
5. Glassmorphism surfaces, aurora gradients, layered depth, and subtle motion.
6. Animated hero metrics and floating product cards.
7. Transparent reward-draw math and operational lifecycle UI.
8. Charity impact metrics and contribution slider.
9. Winner scorecard proof experience.
10. Recruiter-friendly User Demo and Admin Demo access.
11. Admin reporting charts and audit-oriented surfaces.
12. Reduced-motion support for accessibility.

### Core domain deviation

The original PRD is golf-specific. This variant translates the same platform pattern to cricket so the product story is immediately understandable to a cricket audience.
